## PASOS PARA CONTINUAR EN LA OTRA PC

1. Clonar el repo:
   git clone https://github.com/JhosepCS/tropigo-ai.git
   cd tropigo-ai

2. Copiar el archivo .env (del backup cifrado o crearlo manual)

3. Instalar y correr:
   npm install
   npx prisma generate
   npm run dev

4. La BD ya está en Supabase — NO instalar PostgreSQL.
